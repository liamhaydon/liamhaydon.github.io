Contoso Retail Analytics

Contoso is a fictional global electronics retailer with four years (2021–2024) of sales from stores and an online shop. I built a Power BI report that answers the questions a sales manager would ask, one clear chart per question.

Role
Analyst (solo)
Tools
Power BI · SQL
Data
Contoso sales
Timeline

The data

How it's organized

The data is set up as a star schema: one central table of sales, connected to tables that describe the products, customers and stores behind each sale.

This structure makes it easy to slice the same sales numbers by category, customer or location, which is exactly what each page of the report does.

Reflection

What I learned

Start with the question

Each page answers one business question. Starting there kept the report focused instead of becoming a wall of charts.

Know your data

Understanding how the tables connect made it much easier to build accurate visuals and trust the numbers.

Keep it simple

One chart, one takeaway. Clear titles and a few key numbers say more than a crowded dashboard.
